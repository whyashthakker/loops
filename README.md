# Loops

Demo repo for Cursor loop experiments. Each loop lives in its own folder with its own sample code, checklist, and loop prompt.

## Self-Review Loop

See [`self-improvement/loop.md`](self-improvement/loop.md) to start the loop.

Between iterations, run **checklist review** against [`self-improvement/checklist-review.md`](self-improvement/checklist-review.md).

Sample code and tests for this loop are in [`self-improvement/`](self-improvement/).

## Product Evaluation Loop

See [`product-evaluation/loop.md`](product-evaluation/loop.md) to start the loop.

Between iterations, run **product evaluation** against [`product-evaluation/evaluation-criteria.md`](product-evaluation/evaluation-criteria.md) and document results in [`product-evaluation/findings.md`](product-evaluation/findings.md).

Sample product data for **BGBlur** (https://bgblur.com) lives in [`product-evaluation/products/bgblur/`](product-evaluation/products/bgblur/).
